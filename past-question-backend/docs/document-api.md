# Document API

All routes use the `/api/v1` prefix by default.

## Admin upload

`POST /api/v1/admin/products/:productId/documents`

Authentication: `ADMIN` or `SUPER_ADMIN`.

Content type: `multipart/form-data`.

Fields:

- `file`: PDF, required, maximum 25 MiB by default.
- `title`: required string.

The server returns document metadata. Storage keys are never returned.

## Admin list

`GET /api/v1/admin/products/:productId/documents`

Returns document metadata including lifecycle status and processing/integrity metadata.

## Admin get

`GET /api/v1/admin/documents/:id`

Returns a single document metadata record.

## Admin update/disable/delete

`PATCH /api/v1/admin/documents/:id`

Allowed fields:

- `title`
- `status`: `READY`, `DISABLED`, or `DELETED`

A deleted document cannot be modified.

`DELETE /api/v1/admin/documents/:id`

Soft-deletes the document (`DELETED`) and removes the private storage object on a best-effort basis.

`POST /api/v1/admin/documents/:id/retry`

Retries a `FAILED` document only when its encrypted artifact still exists and passes integrity validation.

## Student authorization

`POST /api/v1/content/:documentId/access`

Body:

```json
{ "deviceId": "server-device-id" }
```

Requires an authenticated student session. The server validates the complete entitlement chain and returns a short-lived `authorizationToken`.

## Student artifact

`GET /api/v1/content/:documentId/artifact`

Requires the normal authenticated `Authorization: Bearer <access-token>` header plus:

`X-Content-Authorization: <authorizationToken>`

The response is the encrypted `.pqe` artifact as `application/octet-stream`. It is not a plaintext PDF and is not a public storage URL.

## Security behavior

A missing/invalid session, content token, device, license, paid purchase, active product, or READY document results in denial. Resource identifiers are not accepted as proof of ownership.

## Device registration key

`POST /api/v1/devices/register` may include `publicKey`, an RSA public key generated by the mobile app. The private key must remain on-device.

The artifact endpoint returns the device-wrapped document key in the `X-Document-Key` header. The artifact itself is the encrypted `.pqe` object.
